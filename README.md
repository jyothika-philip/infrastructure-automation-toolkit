# infrastructure-automation-toolkit

A collection of hands-on infrastructure automation projects built using PowerShell, Windows Server, Active Directory, Linux, and Microsoft technologies.

The goal of this repository is to demonstrate practical system administration skills through real-world automation projects commonly performed by IT Administrators, Systems Engineers, and Infrastructure Engineers.

---

## Technologies

- PowerShell
- Windows Server 2025
- Active Directory Domain Services
- Windows 11
- Linux (Ubuntu Server)
- VirtualBox
- CSV Automation
- Microsoft 365 (planned)
- Microsoft Entra ID (planned)
- Microsoft Intune (planned)
